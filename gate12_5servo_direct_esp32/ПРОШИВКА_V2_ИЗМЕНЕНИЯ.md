# Gate12 Direct5 Safe Firmware 2.0.0

Подготовлено 2026-09-22. На момент сборки ESP32 физически отключена; загрузка в
плату ещё не выполнялась.

## Что улучшено

1. Аппаратный программный interlock: ESP32 отклоняет второй производственный
   `CYCLE`, пока любой канал ещё движется. Даже ошибка в программе ПК больше не
   должна запустить несколько серв одновременно.
2. Калибровка больше не записывается повторно в NVS, если HOME/ВЫДАЧА не
   изменились. Приложение также перестало отправлять `CAL` перед каждой банкой.
3. Новый защищённый протокол `CYCLEID` с token. Запоздалый `DONE` от старой
   операции не может закрыть новую операцию.
4. До движения проверяются:
   - наличие сохранённой калибровки;
   - hard limits 700..2300 мкс;
   - разница HOME/ВЫДАЧА не менее 20 мкс;
   - попадание обеих точек в индивидуальные safe limits;
   - hold 50..5000 мс;
   - отсутствие другого движения.
5. Добавлены команды `STOP ALL`, `DETACH ALL`, `VERSION`.
6. По умолчанию hold изменён на 900 мс.
7. `INFO` теперь показывает token текущего цикла.
8. Ошибки ESP32 немедленно останавливают операцию в приложении; ожидать общий
   тайм-аут больше не требуется.
9. Дедлайны приложения переведены на monotonic clock и не зависят от перевода
   системных часов.
10. Сообщение об отказе доступа к COM теперь прямо сообщает, что порт занят
    другой программой.
11. По официальному примеру ESP32Servo заранее выделяются все четыре LEDC
    таймера, а каждому Servo явно задаётся стандартная частота 50 Гц.
12. После подключения или переподключения ПК сначала выполняет STOP+DETACH всех
    каналов и только затем синхронизирует калибровку.
13. Вторая копия панели оператора на Windows блокируется, чтобы два процесса не
    спорили за один COM-порт.
14. `VERSION` и `READY` сообщают причину последнего reset и uptime; подключение и
    версия прошивки записываются в журнал ПК для диагностики brownout/watchdog.

## Обратная совместимость

Приложение при подключении отправляет `VERSION`:

- firmware v2 с `cycle_id=1` → используется `CYCLEID`;
- старая firmware → автоматически используется прежний `CYCLE`.

Поэтому новая программа безопасно запускается и до перепрошивки, но interlock и
tokens заработают только после загрузки v2 в ESP32.

- `py_compile` обоих Python-файлов: пройден.

## После подключения ESP32

1. Оставить питание серв выключенным.
2. Закрыть все программы, которые держат COM-порт.
3. Загрузить прошивку командой из `flash_firmware_v2.ps1` либо через
   `arduino-cli upload`.
4. Проверить `PING`, `VERSION`, `INFO ALL` без питания серв.
5. Только после этого включить питание серв.
6. Сначала выполнить по одному холостому циклу каждого канала без банки.
7. Затем выполнить цикл каждого канала с банкой.
8. Затем проверить группу 2→3→4→5.
