# ОТБРАКОВАНО — опрокидывающаяся люлька


Этот вариант **не печатать и не использовать**. Он сохранён только как проверенная и отклонённая ветка, чтобы не вернуться к той же ошибке.


Причина: при ходе 50° задняя кромка касается следующей банки слишком низко; при ходе, достаточном для надёжной выдачи, обратный момент полной очереди приближается к пределу SG90 или превышает его. Дополнительно аудит обнаружил коллизии и разрыв дорожки. В итоговое сравнение вариант не входит.


Рабочих печатных деталей на канал: **2**. Серва — одна существующая SG90/MG90S.


HOME: дорожка люльки продолжает скат, первая банка упирается в переднюю стенку.

Переход: задняя кромка поднимается между первой и второй банками, пока передний упор ещё закрыт.

EJECT: передний упор полностью уходит вниз, наружу выходит банка, уже находившаяся в люльке.


Крепление: два одинаковых M3 с потайной головкой через передний край нижнего листа. Рама находится в зоне свеса коробки и не требует балки или подиума.


Проверки генератора: сетки=True, стол 220×220=True, перекрытие фаз=True. Это полноразмерный прототип для сравнения; до тиражирования обязателен один физический канал и 300 циклов.
