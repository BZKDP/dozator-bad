# ОТБРАКОВАНО — не печатать

Эта ветка сохранена только как журнал проверенной ошибки. При реальном ходе задняя кромка не удерживает следующую банку на безопасной высоте, а увеличение хода делает возврат полной очереди слишком тяжёлым для SG90. Дополнительно обнаружены коллизии рамы, сервы и люльки, а также разрыв дорожки. В итоговые три варианта V11 она не входит.
