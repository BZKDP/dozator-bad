ДОЗАТОР БАД — ЗАТВОР №12, версия v9 (SG90 + грузики)
============================================================================
Ender 3 V3 SE + Creality Print. Стенка картона: высота 47, толщина 3 мм.
Серво — МАЛЕНЬКОЕ (SG90/MG90S). Вариант под MG996R сохранён в stl_gate12_MG996R_backup.

ЧТО НОВОГО В v9
  • Узел лёгкий — банки его сбрасывают. Решение: всё КЛЕИТСЯ + добавлены грузики.
  • НОЖКИ остаются ОТДЕЛЬНЫМИ (впаять нельзя — они смотрят вниз, а башни вверх,
    в одной печати это дало бы поддержки). Ты их ВКЛЕИВАЕШЬ суперклеем в пазы
    рамы -> получаешь один жёсткий узел. Затем весь узел клеишь к картону.
  • ГРУЗИКИ: 4 бобышки по углам рамы с ШЕСТИГРАННЫМ карманом под гайку M10
    (под ключ 17). Гайку вкладываешь и клеишь. Рама 31->39 см3, масса ~38->~93 г
    (с 4 гайками M10). Верх бобышек плоский — можно доклеить самоклеящиеся
    балансировочные грузики (5/10 г полоски).

ЧТО КУПИТЬ ДЛЯ ВЕСА (Ozon/WB)
  • ГАЙКА ОЦИНКОВАННАЯ M10 DIN934 (под ключ 17, ~11 г) — по 4 шт на узел.
    Ищи «гайка М10 оцинкованная» — копейки, лежит в любом строительном.
  • ИЛИ самоклеящиеся балансировочные грузики: «грузики балансировочные
    самоклеящиеся» (Fe, полоски 12×5 г ~14 см) — клеятся куда угодно, режутся.
    Ozon: /category/balansirovochnye-gruziki-samokleyushchiesya/

============================  ПЕЧАТАТЬ  ============================
ГЛАВНОЕ — plate_chassis.stl (только рама, с бобышками грузиков), ПЕРЕПЕЧАТАТЬ:
  Вид → Высота слоя: 0.3 · Прочность → Периметры: 3 (крепче под вес) ·
  Сплошных сверху/снизу: 4/4 · Плотность заполнения: 25% · Шаблон: Гироид ·
  Прочее → Тип каймы: Внешняя 3 мм · Поддержки: ВЫКЛ

ШЕСТЕРНЯ (plate_gear.stl) и РЕЙКИ/НОЖКИ/ПАЛЕЦ — БЕЗ изменений, что напечатано —
оставляешь. Если печатаешь набор с нуля — plate_rest.stl (всё вместе) + plate_gear.stl.
  plate_gear: слой 0.2 / периметры 3 / 40% / без каймы / поддержки ВЫКЛ.

============================  СБОРКА  ============================
  1. Ножки (4) вставить иглой в торец картонной стенки, штырь в паз рамы,
     КАПЛЯ суперклея в паз (узел становится жёстким).
  2. В 4 бобышки вложить по гайке M10 + капля клея. (Мало — доклеить самоклейку.)
  3. Качалку SG90 на серво штатным винтом; шестерню на качалку; палец снаружи
     через дальнюю втулку + клей. Рейки сверху в каналы зубьями к шестерне.
  4. Весь узел приклеить к картону.
