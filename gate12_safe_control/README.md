# Gate12 safe control: ESP32 + MG90S

Этот комплект для одного напечатанного затвора №12: `шестерня + две рейки`.
Он не запускает авто-тесты и не делает sweep. После включения ESP32 серво не
двигается, пока ты сам не нажмёшь кнопку в окне на ПК.

## Провода MG90S

Обычно у MG90S:

| Провод серво | Куда подключать |
|---|---|
| коричневый/чёрный | `GND` |
| красный | `+5V` |
| оранжевый/жёлтый | сигнал |

## Быстро напрямую, один серво без большой нагрузки

ESP32 подключена к компьютеру по USB.

| MG90S | ESP32 DevKit |
|---|---|
| оранжевый/жёлтый signal | `GPIO13` |
| красный `+` | `5V` или `VIN` |
| коричневый/чёрный `-` | `GND` |

Красный не вставлять в `3V3`.

Этот вариант годится только для аккуратной первой проверки с маленьким ходом.
Если серво дёргается, ESP32 перезагружается или механизм уже нагружен банками,
питай серво отдельно.

## Правильно под механизмом

ESP32 всё равно остаётся в компьютере по USB, а MG90S питается от отдельного
блока 5-6 В.

| MG90S | Куда |
|---|---|
| оранжевый/жёлтый signal | `GPIO13` ESP32 |
| красный `+` | `+5V` внешнего БП |
| коричневый/чёрный `-` | `-` внешнего БП |
| `-` внешнего БП | `GND` ESP32 |

Общая земля обязательна: минус блока питания и `GND` ESP32 должны быть соединены.
Без пайки это удобно собрать Dupont-проводами через макетку, клеммник WAGO или
маленький винтовой клеммник.

## Прошивка

### ESP32

1. В Arduino IDE установи библиотеку `ESP32Servo`.
2. Открой:
   `gate12_esp32_safe/gate12_esp32_safe.ino`
3. Выбери свою ESP32 плату и COM-порт.
4. Загрузи скетч.

По умолчанию сигнал серво стоит на `GPIO13`. Если хочешь другой пин, поменяй
строку:

```cpp
const int SERVO_PIN = 13;
```

### Arduino Mega

Для Mega отдельная прошивка лежит здесь:

```text
gate12_mega_safe/gate12_mega_safe.ino
```

Подключение одного MG90S к Mega:

| MG90S | Arduino Mega |
|---|---|
| оранжевый/жёлтый signal | `D9` |
| красный `+` | `+5V` внешнего БП 5-6 В |
| коричневый/чёрный `-` | `-` внешнего БП и `GND` Mega |

Mega подключается к компьютеру по USB. Можно дополнительно питать саму Mega через
круглый разъём 7-12 В, но серво лучше не кормить через стабилизатор Mega.
Если используешь один хороший стабилизированный блок 5 В, можно питать серво от
него, а Mega оставить на USB; главное — общая земля.

## Окно с ползунком

В этой папке:

```powershell
pip install pyserial
python .\gate12_safe_slider.py
```

Порядок первого запуска:

1. Открой окно, выбери COM-порт ESP32, нажми `Подключить`.
2. Подключение не двигает серво.
3. Оставь узкие лимиты `1450..1550`, нажми `Включить серво на этом положении`.
4. Двигай ползунок маленькими шагами влево/вправо.
5. Если ничего не упирается, расширяй лимиты по 50-100 мкс.
6. Когда нашёл безопасное положение покоя, нажми `Покой = текущее`.
7. Когда нашёл положение, где банка выходит, нажми `Выдача = текущее`.
8. Нажми `Выдать 1 банку`.

Если направление оказалось наоборот, нажми `Поменять`.

Кнопка `Стоп` прекращает текущий цикл и временно отключает отправку команд от
ползунка. `Отключить сигнал` снимает PWM-сигнал с серво.
