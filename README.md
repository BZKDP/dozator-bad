# Дозатор БАД — гравитационный дозатор банок

Механический дозатор флаконов с пищевыми добавками: гравитационная полка на 28 дорожек.
Банки лежат на боку столбиком в вертикальном магазине и под собственным весом опускаются
к затвору. V-образный жёлоб сводит дорожки к центру, где сидит фасовщик.

## Механика
Затвор работает по принципу escapement (как в торговых автоматах). На дорожку приходится
два шлагбаума в противофазе — за цикл они изолируют и роняют ровно одну банку. Привод затвора:
печатная шестерня (модуль 2, Ø ~48 мм, 24 зуба) и две зубчатые рейки, которые двигает один
сервопривод SG90 штатной качалкой в кармане рамы. Эталонная банка — Ø47 × 67 мм; при других
размерах достаточно поменять два числа в генераторе геометрии, остальное пересчитывается.

## Состав репозитория
- `stl_gate12/` — финальный набор STL затвора + генератор `make_gate12.py` (OpenSCAD/Python через trimesh).
- `stl_gate12_SG90_backup/`, `stl_gate12_MG996R_backup/` — прежние варианты привода (архив).
- `gate12_5servo_direct_esp32/`, `gate12_5servo_pca9685/`, `gate12_safe_control/` — прошивки ESP32/Arduino (управление сервами, LEDC) и настольная панель оператора `*_full_app.py`.
- `servo_*`, `uno_*`, `dispense_test` — тестовые скетчи сервопривода.
- `dispenser_pc.py`, `servo_panel.py`, `gate_control.py` — управление с ПК по последовательному порту.
- `*.html` — 3D-визуализации узлов и компоновок (three.js, `libs/`).
- `v9…v15/` — итерации конструкции магазина и кассеты (генераторы, STL, чертежи раскроя).
- `ЧЕРТЁЖ-и-сборка.md` — размеры, схема механизма, раскрой и порядок сборки.

## Печать и сборка
Печатать на FDM (отлажено на Ender 3 V3 SE): шестерня — слой 0.2, рейки и рама — слой 0.3,
периметры 3, без поддержек. Сборка и настройка серв описаны в `ЧЕРТЁЖ-и-сборка.md`
и `stl_gate12/README_печать.txt`. Прошивка подключается к ПК как COM-порт.

## Статус
Рабочий прототип. Открытый вопрос — угол раскрытия затвора (~10,6°) и надёжность сброса
лёгкого узла (решается догрузкой рамы). Firmware управляется по USB-serial, без Wi-Fi.
